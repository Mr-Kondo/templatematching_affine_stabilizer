# 操作と入出力

[READMEへ戻る](../README.md)

以下はリポジトリのルートで実行します。

### GUI モード（デフォルト）

```bash
uv run python app.py
```

または動画ファイルを明示的に指定:
```bash
uv run python app.py --video 01_input/input.mp4
```

### GUIで設定して実行する

1. 先頭フレームを表示し、上部のEntry（入力欄）でテンプレートサイズ（一辺）と上下左右の探索範囲を設定します。
2. 追跡する背景点をキャンバス上でクリックして追加します。基準に使うテンプレートは常に先頭フレームから切り出します。
3. 表（ttk.Treeview）の行をダブルクリックすると値を編集できます。途中で取り消した場合は変更を反映しません。
4. `Delete` で削除し、`Undo` で戻します。IDには欠番が生じる場合があります。
5. `+` / `-` ボタンでズーム（拡大・縮小）し、スライダーで他フレームを確認します。プレビュー位置を変えても基準フレームは変わりません。
6. 異なる中心座標を2点以上用意し、`Execute` で実行します。現在の設定をCSVへ保存してから追跡・補正します。

品質判定は内点3点以上などを使います。完了表示に出た `03_output/run_日時/` の動画と診断CSVを確認してください。
進捗通知はメインスレッドでまとめて消費し、完了・エラーを表示します。

### CLI モード（バッチ処理）

```bash
uv run python app.py --nogui --outdir 03_output/new_run
```

既存の `Input.csv` を使用してバッチ処理を実行します。

**オプション一覧**:
| オプション | 説明 | デフォルト |
|-----------|------|-----------|
| `--video` | 入力動画ファイルのパス | `01_input/` 内の最初のMP4を自動検出 |
| `--csv` | テンプレート定義CSVのパス | `01_input/Input.csv` |
| `--outdir` | CLI出力先。既存ファイルの上書きを拒否 | `03_output/` |
| `--nogui` | GUIを使わずバッチ処理 | (無効) |

## Input.csv フォーマット

テンプレート位置と探索範囲を定義するCSVファイル:

| カラム名 | 説明 |
|---------|------|
| `No.` | 正の一意ID（欠番可） |
| `x座標` | テンプレート中心のX座標（ピクセル） |
| `y座標` | テンプレート中心のY座標（ピクセル） |
| `テンプレートの大きさ（正方形）` | テンプレートの一辺サイズ（ピクセル） |
| `探索左` | 中心から左方向への探索マージン |
| `探索右` | 中心から右方向への探索マージン |
| `探索上` | 中心から上方向への探索マージン |
| `探索下` | 中心から下方向への探索マージン |

**例**:
```csv
No.,x座標,y座標,テンプレートの大きさ（正方形）,探索左,探索右,探索上,探索下
1,106,242,64,64,128,100,64
2,210,227,64,64,128,100,64
3,573,152,64,64,128,100,64
```

---

### 入力の検証方針（GUI・CLI共通）

- 必須列の不足・重複、欠損、非有限値、非整数、正でないID、ID重複をエラーにします。行の値が不正な場合は行と項目を表示します。列不足・重複などはCSV全体のエラーとして表示します。
- 座標は0始まりで、中心を画像内に置きます。テンプレートの一辺は2以上の偶数、短辺の画像寸法以下です。奇数を自動丸めしません。
- 各探索マージンはテンプレート半辺以上、対応する画像寸法以下です。異常なサイズによる過大なパディングを防ぎます。
- 中心が画像内なら、画像端をまたぐテンプレート・探索領域は従来どおり黒でパディングします。完全に画像外の領域は拒否します。黒領域が多い場合の相関の信頼性は保証しません。
- 相似変換の推定には異なる中心座標が最低2点必要です。品質診断は従来どおり内点3点以上・配置の広がりなどを別に判定します。入力を受理したことは品質合格を意味しません。
- GUIの追加・編集・CSV読込・実行前に同じ規則を適用します。編集の途中で取消した場合は変更しません。

## 出力ファイル

GUIは `03_output/run_日時/`、CLIは `--outdir` のフォルダへ出力します。
既存成果物は上書きしません。処理中は専用一時フォルダを使い、4つの出力が完成してから順に公開します。
動画は書込後に再読込してフレーム数を確認します。通常の例外時は途中ファイルを削除し、既存ファイルを保持します。
強制終了・電源断では一時フォルダや一部の公開済みファイルが残る可能性があります。


### Matched.csv
各フレームでのテンプレートマッチング結果:
| カラム | 説明 |
|-------|------|
| `Frame_No` | フレーム番号(2..K。フレーム1はテンプレート抽出の基準のためマッチング対象外) |
| `Template_No` | テンプレート番号 |
| `x`, `y` | 基準座標（1フレーム目のテンプレート中心） |
| `mx`, `my` | マッチング座標（サブピクセル精度） |

`Frame_No = k` は入力・出力の両方のフレーム番号 k に一致します（ずれなし）。

### Matched_diagnostics.csv (v0.6.0以降)
マッチングの信頼度診断(フレーム×テンプレートの各行に対応):

| カラム | 説明 |
|-------|------|
| `score` | CCORR ピーク値(採用基準) |
| `clearness` | 主ピーク周囲7×7を0にした相関面の最大値との差 |
| `ccoeff_peak` | `TM_CCOEFF_NORMED` のピーク値(遮蔽検出のアラーム専用) |
| `roi_edge` | ピークがROI端に到達したか |
| `delta_px` | 同じテンプレートの前フレーム位置からの差(px) |
| `re_searched` / `expanded_adopted` | 低信頼時の拡大再探索の実施 / 採用 |
| `low_conf` | 低信頼フラグ(いずれかの基準が閾値を越えた) |

### Affined.mp4
アフィン変換によりブレ補正された出力動画。

- **出力フレーム数は入力と同一**で、入力のフレーム番号 k と出力のフレーム番号 k が1対1に対応
- フレーム1（テンプレート抽出の基準フレーム）は、アフィン恒等変換 + 固定の透視変換（後述）で出力
- フレーム2以降は、推定したアフィン行列 + 固定の透視変換の合成で出力
- FPSは入力の平均FPSで固定フレームレート出力（可変FPS入力は再タイミング。音声は含まれない）

---

### Affined_diagnostics.csv (v0.6.0以降)
アフィン推定の品質診断(推定したフレームごとに1行):

| カラム | 説明 |
|-------|------|
| `frame`, `points`, `inliers` | フレーム番号 / 制御点数 / RANSAC採用点数 |
| `inlier_ratio`, `residual_max` | 採用率 / 採用点の最大残差(px) |
| `spread_x`, `spread_y` | 採用点の軸別標準偏差（品質判定の補助値） |
| `d_t`, `d_scale`, `d_rot` | 前フレームからの行列変化量(移動px/スケール/回転°) |
| `est_ok` | 推定成功 |
| `quality_ok` | 品質合格(推定成功とは独立の判定) |

## 既存の入口とエラーへの対処

従来の `uv run python 02_code/affine_template_matching.py` も同じ引数で使用できます。
初回探索の範囲はCSVで定義します。低信頼時にはさらに拡大するため、探索範囲は移動量の厳密な上限ではありません。
テンプレート64pxで左64px・右128pxなら、初回の中心探索範囲は基準から左32px・右96pxです。

CLIで既存出力がある場合は `既存出力は上書きしません` と表示して終了コード2で停止します。
既存成果物を保存したまま、`--outdir` に別のフォルダを指定してください。
奇数サイズでは `行2 テンプレートの大きさ（正方形）: 偶数を指定してください` のように表示します。
該当行を偶数へ修正して再実行してください。

推定失敗（`affine fail`）や動画の途中読込・書込検証失敗は処理を停止します。
品質不合格・低信頼だけなら出力を続けます。補正動画に加えて両診断CSVを確認してください。
音声の保持、可変FPSの元タイミング保持は行いません。
