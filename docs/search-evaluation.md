# 予測探索・粗密探索の比較（Issue #15）

[READMEへ戻る](../README.md)

現時点では、予測位置を使う探索縮小と2段の粗密探索を本番に採用しません。
予測探索は遮蔽・探索端で位置誤差が増え、粗密探索は今回の条件では追加実装を正当化する十分な根拠に至りませんでした。

## 比較条件

`uv run python benchmarks/search_candidates.py --output 03_output/search-new.json` で再現できます。
出力先は新規ファイルにしてください。seed 42/43/44、640×360、61フレーム、5点、
初期テンプレート32px、各探索マージン96pxを使います。既存のsynth.build_base_sceneを再利用します。
通常移動は平行移動・回転・倍率の小さい周期変化、急変は25フレーム目から55/-30pxの段差、
探索端はX方向88pxの振幅、画面端は4隅から4pxの中心、遮蔽は20〜35フレーム目の1点を覆う矩形です。

- baseline: 本番の固定ROI探索と低信頼時の拡大再探索。
- prediction: 前回座標＋前回移動量の周囲（テンプレート半辺＋16px）を探索。
- pyramid: 1/2画像の粗いピークから原寸の±4pxを探索。
- 両候補とも初期テンプレートを維持します。局所探索はCSVのROI内に制限し、スコア・明瞭さ・探索端・CCOEFF警告で元方式へ戻します。
- 座標はROI左上＋ピーク位置＋テンプレート半辺で画像座標へ戻します。既知の3/5px並進を単体テストで確認しました。

## 結果

各seedの値の平均（位置誤差・背景残差）、3seed間の中央値（追跡時間ms）。
背景残差は追跡に使わない12点前後に、正解運動と推定逆変換を適用した幾何誤差です。
固定透視変換は除き、基準画像の座標系で評価します。

復帰成功は「復帰した照合の位置誤差が2px以内」の件数で、遮蔽後の回復保証ではありません。

## 採否と限界

予測探索は遮蔽の平均誤差が7.96→10.33px、探索端が14.32→18.31pxに増えました。
低信頼判定を通過する誤ピークがあり、探索縮小を一律に適用する根拠が不足しています。
粗密探索は多くの条件で位置が維持されましたが、通常条件の追跡は約603→517msに留まります。
コード・閾値・復帰状態の保守負担に対して、実動画や多様な探索寸法での再現性が不足しています。
画面端は高速化しても誤差や復帰失敗が残ります。今回の採否は不採用とし、固定ROIの意味を変更しません。

これは3seedの合成画像をデコード済みで比較した結果です。読込・圧縮・描画・動画書出しを含むアプリ全体の速度向上ではありません。
本番方式自体もこの合成条件で数px〜十数pxの平均誤差があり、本番方式の正確さを証明する比較ではありません。
未観測の動画、探索寸法、予測器の調整によって結果は変わり得ます。
